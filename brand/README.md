# Brand Assets

Organization-level branding. Owned by `yakoon-runtime/.github`, not by any
single repository — Yakoon's logo represents the whole organization, not
the runtime.

```
brand/
├── master/        — Source files (SVG master)
├── png/           — Raster logos (dark, light, glyph)
├── svg/           — Vector logos
├── social/        — GitHub avatar, banners etc.
└── README.md
```

## Verwendung

- **Organisationsprofil**: `../profile/README.md`
- **Web-Client**: `apps/y5n-apps-web/src/y5n/apps/web/static/`
- **Textual-Client**: Als Text-Logo oder ASCII-Kunst
- **Dokumentation**: `docs/`
